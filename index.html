Hyun Icon

Hyun Icon은 웹사이트에서 자주 사용되는 100개의 아이콘을 하나의 10×10 CSS Sprite로 구성한 간단하고 가벼운 아이콘 세트입니다.

CSS의 background-position을 이용하여 원하는 아이콘을 선택할 수 있으며, 별도의 JavaScript나 외부 라이브러리 없이 사용할 수 있습니다.

사용 방법

공통 클래스인 icon과 원하는 아이콘 이름을 함께 지정합니다. 여러 단어로 이루어진 아이콘 이름은 하이픈(-)으로 연결합니다. 

<i class="icon home"></i>
<i class="icon search"></i>
<i class="icon arrow-left"></i>
<i class="icon fast-forward"></i>

특징

  • 100개의 웹 UI 아이콘
  • 10×10 CSS Sprite 방식
  • 아이콘 이름은 하이픈(-)으로 구분
  • 간단한 <i> 태그로 사용
  • JavaScript 없이 사용 가능
  • 외부 아이콘 라이브러리 불필요
